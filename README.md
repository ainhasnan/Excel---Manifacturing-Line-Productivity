# Excel-Manifacturing-Line-Productivity
Productivity &amp; downtime data for a soda bottling production line, including information on the operator, product, start &amp; end times, and dowtime factors for each batch.

## Analysis

* **Current Line Efficiency:** Compare total production time against minimum required time.
* **Underperforming Operators:** Identify operators with lower efficiency or higher error rates.
* **Factors Affecting Performance:** Identify key causes of underperformance, including machine adjustment skills and operator errors.

## Key Findings

* **Product OR-600:** Demonstrates high efficiency but relatively low production output.
* **Operator Dee:** Recorded a higher error rate despite handling high-volume production products.
* **Machine Adjustment Proficiency:** Dee is still developing proficiency in machine adjustments, which may contribute to production errors and reduced performance.

## Key Features**
* Query - merging data, calculate time duration
* Pivot table
